# TOEIC 攻略 · 多益備考平台

一個完整的多益(TOEIC)備考網站,純前端 HTML 單檔即可運作,支援桌機與手機。

🔗 **線上試用**:https://jungcharlix.github.io/toeic-prep/

---

## ✨ 主要功能

### 📖 商務單字 · 雙模式學習
- **翻卡記憶**:40 個多益核心高頻單字,分 8 大情境分類(商業、辦公室、財務、人事、行銷、旅行、物流、會議),點擊翻卡看中譯與例句
- **單字測驗**:三種題型(英→中、中→英、克漏字)+ 綜合題型隨機混搭,即時顯示對錯與解析
- 智慧連動:測驗答對自動標記為已學會,可一鍵翻卡複習錯題

### ✍️ 文法測驗 · Part 5
- 15 題句子填空題型訓練
- 涵蓋時態、被動語態、介系詞、關係代名詞、條件句等核心文法
- 作答後立即顯示詳細中文解析

### 📚 閱讀理解 · Part 7
- 3 篇商務情境短文(電子郵件、公告、備忘錄)
- 共 9 題理解測驗,附中文解釋

### 🎯 真題演練 · 8 回完整模擬試題
- **160 道題目**,每回 20 題、20 分鐘倒數計時
- 涵蓋 **Part 5 / 6 / 7** 三大題型
- 主題分布:辦公室、行銷、物流、人事財務、科技、醫療、不動產、教育
- 三個難度等級(初級 / 中級 / 進階)
- 題目導航面板、標記待檢查、未答提示

### 🩺 個人化學習診斷
完成真題後可進入「詳解」頁面,獲得:
- **焦點建議 Banner**:系統挑出最該優先解決的問題
- **能力等級評估**:估算 TOEIC Reading 分數區間
- **Part 5/6/7 分項表現**:逐項正確率分析
- **22 種知識點掌握度**:時態、被動、介系詞、連接詞、關代等
- **對症下藥處方箋**:每個弱點都附問題診斷、學習建議、練習方向、相關錯題連結
- **逐題詳解**:選項對照、干擾項分析、記憶口訣、再試一次練習

### 📊 學習進度追蹤
- 即時統計已學單字、答題正確率、最高連勝
- 各單字分類學習進度
- 真題演練歷史成績

## 🛠 技術特色

- **零依賴**:單一 HTML 檔案,無需後端、無需 npm,直接打開就能用
- **完全響應式**:手機、平板、桌機都有最佳化版面
- **本地儲存**:學習進度自動保存在瀏覽器中
- **離線可用**:檔案下載後不需要網路也能練習

## 🎨 視覺風格

採用極簡現代設計 — 純白底搭配藍色強調,Inter 字體,圓潤的卡片元件,參考 Linear / Notion / Stripe 等現代產品的視覺語言。

## 📱 使用方式

1. **線上版**:直接訪問上方的線上連結
2. **本地版**:下載 `index.html` 後用瀏覽器打開即可

## 🚀 部署

本專案使用 GitHub Pages 部署,純靜態檔案無需任何建置流程。

Fork 本專案後:
1. 進入 Repository → Settings → Pages
2. Source 選 `Deploy from a branch` → `main` / `root`
3. 等 1-2 分鐘即可透過 `https://你的帳號.github.io/toeic-prep/` 訪問
